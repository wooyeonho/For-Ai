## 2. What G6 now is, locally

`migrations/0005_functional_self.sql` (SHA-256
`9e39681171f9af12e31d1b294f6f060905da690f51017f8846bd004b8bfd25fd`) adds:

- `constitution_rules` — 6 seeded rules, hard rules flagged, each with a source ref.
- `identity_kernel` — versioned self-statement + traits, one active version,
  `superseded_by` chain, constitution hash bound into the version.
- `memory_items` — episodic / semantic / procedural / owner / decision / evidence,
  each with source, confidence, salience, observed vs recorded time. Append-only:
  `trg_memory_no_delete` refuses deletion, `trg_memory_supersession_final`
  refuses resurrecting a superseded row.
- `desires` — 6 explicit desires with baseline weights; `desire_activations`
  record every firing with its trigger kind and reference.
- `homeostasis` — 4 measurable metrics, all "lower is better" against target 0,
  so activation comes from a number, not from prose.
- `goals` — statement + rationale + originating desire + activation, priority
  in `-40..100`, states `PROPOSED/SELECTED/REJECTED/DONE/ABANDONED`.
- `council_sessions` / `council_arguments` / `council_verdicts` — the internal
  debate is a record. `trg_verdict_needs_debate` requires at least one FOR and
  one non-FOR argument; `trg_verdict_violation_needs_rule` requires a named rule
  when the constitution check fails; `trg_goal_select_needs_verdict` makes
  `SELECTED` reachable only through a passing verdict.
- `self_model_answers` — 10 fixed questions, each requiring an evidence ref.
  `trg_self_no_consciousness_claim` refuses to store a claim of consciousness,
  sentience or life in Korean or English. This is functional self-modelling.

`src/domain/self.mjs` is the only writer: `remember`, `supersede`, `recall`,
`observe`, `activateDesires`, `proposeGoal`, `openCouncil`, `argue`,
`checkConstitution`, `decide`, `abandonGoal`, `publishIdentity`,
`answerSelfModel`, `selfReport`, `goalTrace`. `selfReport()` returns
`prep_only: true` so no caller can read this as a passed gate.

CLI surface: `self report`, `self remember`, `self observe`, `self activate`,
`self trace <goalId>`.

## 3. Tests (test/functional-self.test.mjs, 11 tests)

1. G6 stays PREP_ONLY and is never promoted by implementation alone.
2. Memory is append-only; a correction supersedes instead of rewriting.
3. Desires activate from measurable internal state, not from prose — and stay
   silent when there is no deviation.
4. A goal needs a rationale and a desire activation; hidden goals are refused.
5. A goal is only SELECTED through a council verdict with real dissent.
6. The database refuses a SELECTED goal without a passing verdict.
7. A goal that breaks a hard constitution rule cannot be selected (push without
   approval, disabling emergency stop, exfiltrating keys, consciousness claim).
8. A selected goal can be rolled back to ABANDONED without erasing its trace.
9. The self-model needs evidence and cannot record a consciousness claim.
10. A new identity version supersedes the old one and only one stays active.
11. Memory, identity, desires and goals survive a close and reopen.
