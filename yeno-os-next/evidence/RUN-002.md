## Enforced invariants (SQL, not convention)

- a session cannot be checkpointed without a report **and** an unblocked NEXT_RUN entry
- `CLOSED_PASS` requires `evidence_ref`
- a NEXT_RUN entry is consumable exactly once and cannot be deleted
- a blocker cannot leave `WAITING` without a resolution

## Guard hardening

`normalizeCommand()` stripped quotes and backslashes, so `x=push; git $x origin main`
and `git $(echo push) origin main` never contained the literal `git push` and
were allowed. Indirection is now detected on the **raw** string before
normalisation and denied: command substitution, variable expansion,
`eval`/`exec`/`source`/`xargs`, `sh -c` wrappers, `alias`/`function`
definitions. Seeded bypass attempts assert DENY in `test/guards.test.mjs`.
