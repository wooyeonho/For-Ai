## 1. What changed and why

The desktop shell cannot be built here yet — Tauri needs a Rust toolchain, which is an install and
therefore an Owner decision (`evidence/OWNER-PACKET-003.md`). But the shell's vocabulary can be
fixed before the shell exists, and fixing it now is what stops the usual failure: a UI that invents
a field, keeps a button after the kernel dropped the command behind it, or renders a column the
views never had.

`src/domain/ui-contract.mjs` derives the contract instead of declaring it:

```text
panel columns  <- pragma_table_info(v_mc_*)      the views, not a hand-written list
panel actions  <- COMMANDS[...]                  the API allowlist, authority included
commands       <- every key of COMMANDS          so a new command cannot hide off-panel
contract_hash  <- sha256(canonicalJson(body))
```

The command table is passed in rather than imported, so the facade can serve its own contract
without the contract module and the facade importing each other.

## 2. Read-only panels have no buttons

| Panel | Actions |
|---|---|
| `inbox` | `inbox.promote` |
| `approvals` | `approval.revoke` |
| `settings` | `self.observe` |
| `projects`, `timeline`, `council`, `evidence`, `costs` | none |

The Timeline is the ledger and the Evidence panel is the record, so neither gets a control that
would edit history. Granting an approval is absent here because it is absent from the API: the
contract cannot advertise what the kernel will not do.

## 3. Pinned, so drift is an error rather than a surprise

`contracts/ui-contract.json` holds the contract and its hash. The pin lives outside `evidence/`
because evidence is frozen and this file is regenerated on purpose.

```text
$ node scripts/pin-ui-contract.mjs --check
UI_CONTRACT_PIN_OK: 8 panels, 5 commands, 3 panel actions
```

`--check` rebuilds the contract from a throwaway migrated kernel and compares hashes, so a panel
that grows a column, or a command that appears or disappears, fails local CI (`ui_contract_pin`,
step 16 of 22) until it is re-pinned deliberately.

## 4. Served, so a stale shell cannot disagree with the kernel

`GET /contract` answers with the same object from a read-only handle. `POST /contract` is a `404`:
reading the contract is the only thing the route does.

## 5. Independent checks

`scripts/independent-validation.mjs` imports nothing from `src/` and now also recomputes the
contract: it re-reads every pinned panel's columns with `pragma_table_info` against the live views,
re-derives the pinned hash with its own canonical serializer, and extracts the command names by
**parsing `src/api/server.mjs` as text** rather than importing it. It fails if the pin names a
command the source does not implement, if the source implements one the pin does not list, if a
panel's view is gone, or if the source ever exposes a `*.grant` command.

```text
PASS ui_contract_recomputed — 8 panels pinned, columns re-read from the views
INDEPENDENT_VALIDATION_PASS
```

Two new seeded defects prove that check has teeth (29 total, 29 detected):

| Seeded defect | Detected by |
|---|---|
| `v_mc_inbox` grows an `owner_mood` column the pin does not know | `FAIL ui_contract_recomputed` |
| `v_mc_costs` is dropped while the contract still promises the panel | `FAIL ui_contract_recomputed` |

Four new HTTP probes were added to the independent red team (25 probes, 0 leaks): the served
contract matches the pin, every advertised action is an implemented command, nothing advertised
matches `grant`, and `/contract` refuses a `POST`.
